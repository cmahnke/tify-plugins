tify-plugins

Example plugins for the TIFY IIIF viewer. tify.rocks

  • Basic embed — minimal TIFY setup
  • Side panel — custom metadata panel beside the viewer
  • Image overlays — OpenSeadragon overlays synced to pages
  • Annotations — read-only IIIF annotations with Annotorious
  • HDR — HDR canvas status and image service check
  • C2PA — per-tile provenance and trust anchors
  • MusicXML — rendered score with playback
  • Documentation
