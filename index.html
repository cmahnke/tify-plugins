tify-plugins

Modular plugins for the TIFY IIIF viewer — annotations, overlays, HDR status, C2PA provenance and score playback, docking straight into the viewer chrome. tify.rocks

  • Basic embed

    Load any IIIF manifest and see TIFY in action.

  • Side panel

    Custom metadata panel: document title, page count, page status and prev/next/thumbnails controls — docks into the viewer header.

  • Image overlays

    OpenSeadragon overlays synced to pages — TEI word boxes or demo markers.

  • Annotations

    Display-only IIIF annotations rendered as shapes, with a linked list panel.

  • HDR

    HDR capability status and image service check with a tinted dock button.

  • C2PA provenance

    Per-tile C2PA provenance for the live viewport with a trust-anchor form.

  • MusicXML score

    Rendered MusicXML notation aligned onto the scan, with Web Audio playback.

  • Documentation

    Rendered READMEs for the monorepo and every package.
