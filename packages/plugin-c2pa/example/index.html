C2PA provenance

Per-tile provenance for the current viewport.

Code example 
import Tify from 'tify';
import { c2paPlugin } from '@projektemacher/tify-plugin-c2pa';

const tify = new Tify({ container: '#tify', manifestUrl });
const plugin = await c2paPlugin(tify, {
  panelEl: document.querySelector('#panel'),
  trustAnchors: 'https://contentcredentials.org/trust/anchors.pem',
});
