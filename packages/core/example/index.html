Info

Lists the plugin-relevant features the manifest and image service advertise: IIIF versions, linked transcriptions, annotations, scores, and HDR/C2PA signals. Features without their plugin also warn in the console (?warnings=0 silences).

Code example 
<!-- Viewer and panel hosts in your markup -->
<div id="tify"></div>
<aside id="panel"></aside>
import Tify from 'tify';
import { infoPanelPlugin } from '@projektemacher/tify-plugin-core';

const tify = new Tify({ container: '#tify', manifestUrl });
// The plugin fills the #panel host above and docks
// a toggle button into the viewer header.
const plugin = await infoPanelPlugin(tify, {
  panelEl: document.querySelector('#panel'),
  dock: 'auto',
  autoOpen: true,
});

// The same feature data without a panel, straight from the IIIF JSON:
import { describeCanvas, describeImageFeatures, describeManifest } from '@projektemacher/tify-plugin-core';

const manifest = { /* parsed manifest JSON */ };
const features = {
  ...describeManifest(manifest),
  ...describeCanvas(manifest, 1),
};
